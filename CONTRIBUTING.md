# Contributing

Open an issue for anything: a question, a disagreement, a hole, a collection that does not fit.

Text changes arrive as pull requests — small, one idea each, with the reason in the description.

A new profile — the guarantees of one kind of Orbital — arrives as a pull request with a measured implementation; see `profiles/README.md`.

Anything larger than a paragraph goes in `proposals/` as a short document: the problem, the change, what it breaks, and what a reader has to do differently. Discussion happens on the PR.

Every accepted or declined change is logged in `CHANGELOG.md` with its reason.

Before your first commit, enable the secret-scan gate once per clone:

    git config core.hooksPath .githooks

Aries Labs edits the document today. Other teams who want to co-edit: open an issue and say so.
